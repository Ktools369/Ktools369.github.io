Privacy Policy

This policy applies to the KTools website and KTools browser extensions for Google Drive, Archive.org and Scribd.

Data collection

KTools does not collect, transmit, sell or share personal information, document contents, browsing history or generated PDF files.

Local document processing

When the user requests an export, a KTools extension may read page metadata, publicly listed files, rendered page content or page images on its supported website. Processing and PDF creation occur locally in the browser. Document data is not transmitted to KTools servers.

Access boundaries

The Drive tool operates only on Google Drive viewer pages. The Archive.org tool uses public item metadata and public files and stops on restricted or protected content. The Scribd tool captures only pages already rendered for the user's current access and does not automate login, supply access keys or call third-party downloader services.

Storage

KTools does not provide user accounts or remote document storage. Generated files remain on the user's device. The static website is hosted by GitHub Pages, and GitHub may process basic request information under its own privacy policy.

Third-party services

Google Drive, Archive.org, Scribd and GitHub are independent services governed by their respective terms and privacy policies. KTools is not affiliated with these services.

Changes

Material changes will be posted here with an updated effective date.
